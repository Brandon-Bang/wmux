- `wmux web`: 라이브 판을 폰 브라우저로, PWA 설치 가능. **read-only + loopback 기본**,

  렌더, **PTY 붙여넣기·a2a execute 경로 금지**(G3)
- 폰 프로토콜 버저닝: `GET /api/config`가 speak/floor/release 보고

## 4. TO-BE — 목표 상태

> **"에이전트 함대를 믿고 방치할 수 있는 유일한 기판"에서
> "다른 에이전트·에디터가 그 기판 안으로 들어와 쓰는 표준 표면"으로."**

| 축 | TO-BE 정의 | 성립 조건 |
|---|---|---|
| **T1 생존** | 재부팅·크래시 후에도 함대가 그 자리 — 유지·강화 | 복원 판이 **suspended 상태로** 돌아와 사람이 ENTER를 눌러야 실행 |
| **T2 표준 표면** | wmux가 **ACP 클라이언트**로서 45종 에이전트를 게이트 *안쪽*에서 몬다 | `terminal/*`→pane 매핑, `session/request_permission`→기존 승인 게이트, `fs/*` 개방 |
| **T3 봉쇄** | 승인 게이트가 힌트가 아니라 **집행기** | OS 프리미티브 샌드박스 + 결정론적 명령 판정 |

| **T5 도달** | 폰에서 함대 지휘 — 읽기가 아니라 **지휘** | iOS 앱 + 입력 경로의 안전한 기본값 |

## 5. 갭 → 액션 (우선순위 확정)

### P0 — 지금

**A. ACP 클라이언트 능력 개방** (L, 최고 ROI)
- 현재: `AcpBrainAdapter.ts:411` fs false / `:285-289` permission 무조건 거부 / deck 전용
- 목표: `session/request_permission` → `ApprovalRegistry`로 라우팅, `terminal/*` → pane 매핑,
  `fs/*` 개방, 일반 판 에이전트로 확대
- **보안 방향**: 완화가 아니라 **강화**다. 지금은 ACP 에이전트가 자기 네이티브 툴로 조용히
  실행하고 우리는 PTY를 훔쳐본다. 열면 그 셸이 우리 게이트를 통과한다
- 의존: `@agentclientprotocol/sdk` **Apache-2.0** 1.3.0
- 파급: 에이전트 45종 + 클라이언트(Zed·JetBrains·Neovim·Emacs·VS Code) 수십 종.
  PTY 스크래핑 → 구조화 diff·plan·permission·session resume **타입 수신**
- ⚠️ 착수 전 **3모델 패널 필수** — 승인 게이트 계약 변경 = 객관 트리거(인증·권한)

**B. 결정론적 명령 판정** (M)
- 현재: `criticalPatterns.ts` anchorless 정규식 11개 = 위험 **힌트**
- 목표: tree-sitter-bash + web-tree-sitter(**MIT, 순수 WASM** — Windows 네이티브 빌드 불필요)로
  컴파운드 분해 → 서브커맨드 추출 → 기존 정규식을 룰 항목으로 **점증 이식**(교체 아님)
- DSL은 OpenAI execpolicy의 allow/prompt/forbidden 3단. OPA/Cedar는 현 규모 오버엔지니어링
- **판정은 100% 결정론적일 것** — Cline이 안전 판정을 모델에 맡겼다가 CVE-2026-52025로 우회당함

**C. 세일즈 포인트 재배치** (S, 코드 0줄)
- README에서 브라우저 자동화를 상단에서 강등(모트 소멸), fan-out 문구를 **hunk 합성 + 감사기록**으로 이동
- "adopt hunks all-or-nothing" 문구 정정 — 실물은 hunk 선택 지원인데 문구가 실물보다 낮다
- `THIRD_PARTY_NOTICES` 정정: MCP 조직 리포가 `NOASSERTION`(npm=MIT, 리포=Apache-2.0 전환문)이라
  **Apache NOTICE 의무를 이미 상속**했는데 "MIT"만 기재

### P1 — 시한부/고임팩트

**D. MCP SDK v2 마이그레이션** (L, 시한)
- v1은 6개월 픽스만. v2 = `@modelcontextprotocol/server` + `/client` 분리, `2.0.0-beta.5`(MIT)
- **완화**: 우리가 stdio 전용이라 stateless·세션 제거·MRTR 등 HTTP 파괴 변경은 대부분 비껴감
- beta라 착수 시점은 GA 근접까지 관망 가능 — 단 **관망을 결정으로 기록**할 것

**E. OS 프리미티브 샌드박싱** (L)
- 2026 생태계 수렴: Claude Code·Codex CLI 둘 다 컨테이너 버리고 OS 프리미티브로
- **`@anthropic-ai/sandbox-runtime`(Apache-2.0)** — Node API(`SandboxManager`) 제공,
  Electron 메인에서 import 가능한 **유일한 프로덕션급 3-OS 옵션**. Windows alpha 실재
- 부족분은 WSL2 이중 프로바이더. Windows Sandbox(.wsb)는 Pro 전용+비영속이라 배제
